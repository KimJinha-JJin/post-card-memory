C / 얕은 홈, 차분한 가장자리

사용자가 고른 얕은 천공을 중심으로 비교해. C1은 기존 C 그대로, C2와 C3는 얕은 원호에 맞춰 홈 입구·종이 연결부·모서리를 함께 설계했어. 최종 채택이나 앱 적용은 아직 하지 않았어.

작게 보일 때 먼저 확인해

브라우저 관찰: 갤러리 크기에서는 홈이 남지만 60dp에서는 약해지고, 38dp에서는 세 안 모두 거의 사각형처럼 읽혀. 깊이를 늘려 보정하지 않았어. C3와 C2의 차이는 작은 크기보다 6배 확대에서 더 분명해.

각 행은 같은 크기의 C1 / C2 / C3야. CSS 1px = 모형 1dp, 브라우저 100% 배율 기준이야. 좁은 창에서는 비교 행만 가로로 밀어 볼 수 있어.

같은 6배로, 홈과 네 모서리

선택한 화면 폭의 사진을 기준으로 위쪽 가운데 40 × 18dp와 네 모서리 18 × 18dp를 6배 확대했어. 좁은 창에서도 배율을 바꾸지 않고 가로 스크롤로 비교해.

홈의 크기와 종이의 폭

사진 한 변과 천공 간격을 기준으로 한 실제 설계값이야. 바깥 윤곽 기준이며 흰 선을 그리기 전 값이야.

설계값C1 · 기존C2 · 정렬C3 · 미세

모든 후보의 명목 흰 여백은 3dp, 그림자는 0이야. C1은 원래 사진 clip과 inset 선 계산을 보존했어. C2/C3는 바깥 윤곽의 안쪽 3dp만 흰 선으로 남겨. 따라서 홈 수치뿐 아니라 흰 선 계산 방식의 차이도 포함된 탐색 비교야.

대한민국 500원 우표 참고 사진은 둥근 홈과 평평한 종이 연결부, 모서리 줄의 연결만 시각적으로 참고했어. 사진 자체를 복제하거나 자원으로 넣지 않았어. C2/C3는 실제 우표의 천공 규격이나 물리 치수를 실측한 결과가 아니야.

B / 같은 천공, 다른 연결

왼쪽은 기존 B, 오른쪽은 개선 B야. 선택한 갤러리 크기를 기준으로 두 안 모두 같은 260px 크기로 확대했어.

윤곽 설계값 · 흰 선을 그리기 전 기준기존 B개선 B

참고 사진에서 확인한 점 · 대한민국 500원 태극기 우표는 둥근 홈 사이에 평평한 종이 다리가 있고, 모서리의 작은 홈도 천공 줄에 이어져 있어. 개선 B는 모서리를 큰 둥근 코너로 깎지 않고, 모서리 홈과 첫 홈 사이도 일반 간격과 같게 맞췄어. 사진의 비율을 육안으로 참고한 설계이며 실측·원본 윤곽 복제는 아니야. 개선 B의 흰 선은 같은 외곽선에서 안쪽으로 계산하고 외곽 밖으로 번지지 않게 잘라, 선 때문에 생기던 둥근 돌출도 줄였어.

모서리 직접 비교 · 좌상 / 우상

더 작은 사용처 · 60dp와 38dp

갤러리보다 작은 우승자·캐릭터 손 사진을 가정한 비교야. 같은 3dp 흰 선을 유지했어.

01 / 전체 비교

같은 갤러리 사진을 최대 220px 정사각형으로 확대했어. 배경·사진·자르기·흰 선은 같고 윤곽만 달라.

02 / 작은 갤러리 크기

3열 그리드의 가로 여백 12dp씩, 칸 사이 8dp를 반영했어. 날짜·배지는 비교에서 뺐어.

03 / 가장자리 확대

위쪽 가운데 40 × 18dp를 최대 6배로 똑같이 확대했어. 둥근 홈 사이에 남은 종이 폭을 봐 줘.

04 / 네 모서리

좌상·우상 / 좌하·우하 순서. 각 모서리의 18 × 18dp를 최대 6배로 똑같이 확대했어.

05 / 화면 폭이 달라지면

두 화면 안에서 A / 기존 B, 개선 B / C 순서로 2행 배치했어. 카드 크기는 원래 3열 갤러리 계산값을 유지했어. 좁은 브라우저에서는 넓은 모형만 가로로 밀어서 볼 수 있어.

비교할 때 기억할 점

A / 현재 삼각 톱니

공통 Kotlin 계산과 사진 clip / inset 흰 선을 이식했어. 원본 앱 캡처와 픽셀 일치를 검증한 결과는 아니야.

B / 둥근 천공형

반원형 홈과 남은 종이 다리를 분리했어. 모서리는 1/4 원형 홈으로 연결해. 실제 종이 섬유·찢김은 표현하지 않았어.

개선 B / 정렬 천공형

한 변을 14등분하고 안쪽 홈 13개와 양쪽 모서리 홈을 같은 격자에 맞췄어. 홈 입구 52%, 평평한 연결부 48%, 깊이는 간격의 26%야. 무작위 요철·섬유 효과는 없어.

C / 얕은 천공형

B와 홈의 입구 폭·반복 수는 같아. 깊이만 60%로 낮췄어. 작은 카드에서 덜 거칠지만, 펀칭 느낌도 약해져.

대한민국 500원 태극기 우표의 로컬 참고 WebP(331 × 295)를 직접 확인했어. 참고 사진은 HTML에 포함하거나 앱 자원으로 편입하지 않았어. 수치는 사진을 육안으로 참고한 탐색값이며, 실제 도구나 우표의 물리 치수를 실측한 값은 아니야.
