① 꾸미기 대화창 — 기준안 / A / B / C

기준안은 코드 값 그대로야: AlertDialog 반경 20dp·종이 흰색(#FFFBF3)·제목 18sp, 입력칸 반경 14dp·#FAF4E9 바탕·#DBCBB0 테두리·포커스 금갈색 2dp, 버튼은 오른쪽 "취소(잉크2)·추가(금갈색 굵게)". 색 고르기는 PostcardCustomColorPicker(색상판·색상 계열 막대 30dp·선택한 색상 원)를 단순화해 그렸어. 대상 대화창 10개(글귀·텍스트 2·라벨 2·테이프 3·도장 1·직접 고르기 1)는 모두 개별 구현이고 같은 값(20/14dp)을 각자 적고 있어.
