스티커 통

달력 사이드바 아래에 신문 인쇄지로 만든 납작한 파우치를 두고, 마음에 든 스티커 조각을 모아 두었다가 다른 엽서에서 다시 꺼내 쓰는 모습을 그려 봤어. 휴대폰 안쪽 크기는 실제 dp 비율이고, 사이드바·달력 치수는 현재 코드(VisitCalendarDrawer.kt)에서 잰 값이야.

브라우저용 목업이야. 실제 앱과 연결되지 않았고, 저장·불러오기·엽서에 붙이기는 동작하지 않아. 제안 표시는 앱에 아직 없는 경로야.

움직임 기기 높이

A. 닫힌 파우치

달력 한 장과 방문 횟수 줄 아래에 붙는 작은 주머니. 입구 위로 최근에 담은 조각 세 개만 살짝 보이고, 조각마다 다른 주기로 아주 조금 흔들려. 파우치를 누르면 C/B-2처럼 보관함이 열려(이 휴대폰에서 직접 눌러 볼 수 있어).

크기와 자리

  • 사이드바 폭 304dp, 안쪽 여백 24dp라 내용 폭은 256dp. 파우치는 132×86dp로 달력 종이 폭의 절반 남짓이야. 달력보다 작고 색도 옅게 둬서 보조 수납처럼 보이게 했어.
  • 지금 사이드바 내용(닫기 버튼부터 방문 횟수 줄과 아래 여백까지)은 계산상 약 476dp야. 달력은 어느 달이든 6주 높이로 고정이라 높이가 달마다 흔들리지 않아.
  • 사용자 기기(약 384×832dp)에서는 아래에 280dp 안팎이 비어 있어서 파우치가 넉넉히 들어가.
  • 작은 기기(360×640dp)에서는 남는 높이가 약 90dp라 파우치 아래쪽이 화면 밖으로 조금 밀려. 사이드바는 이미 세로 스크롤이 있어서 달력을 가리지는 않고, 살짝 밀어 올려야 다 보여(위 버튼으로 바꿔 봐. 빨간 점선이 화면 끝이야).
  • 터치 영역은 파우치 전체(132×86dp)로 48dp 기준을 넘어. 조각 하나하나는 닫힌 상태에서 누를 수 없어(움직이는 걸 정확히 누르게 만들지 않으려고).

B. 열린 파우치, 두 가지 배치

왼쪽은 사이드바 안에서 파우치가 그 자리에서 펼쳐지는 방식, 오른쪽은 사이드바 안의 장면이 달력에서 보관함 한 장으로 넘어가는 방식이야. 오른쪽은 지금 달력이 월·연도 고르기로 넘어갈 때 쓰는 구조(navLevel)와 같은 방식이야. 열린 상태에서는 조각을 고르기 쉽도록 움직임을 멈춰. 조각을 눌러 고르는 것까지 해 볼 수 있어.

비교B-1 사이드바 안 펼침B-2 보관함 장 (사이드바 안 장면 전환)
화면 공간달력 476dp 아래에 붙어서, 열면 스크롤이 필수야. 한 화면에 조각 6~9개.사이드바 높이 전부(약 770dp)를 써. 한 화면에 조각 15~18개.
조작 동선파우치 누르기 → 스크롤 → 고르기. 열 때마다 스크롤 위치가 바뀌어.파우치 누르기 → 바로 고르기. 돌아가기는 ‘← 달력’이나 뒤로 가기.
달력과의 간섭같은 스크롤 안에 있어서, 조각을 스크롤하다 달력 화살표나 제목을 잘못 누를 수 있어.둘이 동시에 보이지 않아서 간섭이 없어.
작은 화면640dp에서는 파우치를 열자마자 대부분 화면 밖이야.높이에 맞춰 줄 수만 바뀌어.
닫기파우치를 다시 누르거나 위로 스크롤.‘← 달력’, 뒤로 가기(지금 BackHandler가 이미 월·연도 고르기 → 달력 순서로 돌아가게 되어 있어).
기존 구조와의 결합달력 Column 안에 펼침 상태와 목록이 섞여 들어가. 달력 높이 고정 원칙은 그대로 둘 수 있어.달력의 AnimatedContent(navLevel)에 단계 하나를 더하는 모양이라 기존 문법과 가장 가까워. 단, 사이드바를 다시 열면 늘 달력부터 보여 주는 규칙(LaunchedEffect)과 맞출지 정해야 해.

C. 빈 스티커 통

아직 아무것도 담지 않은 상태. 입구가 조금 벌어져 안쪽이 비어 보이고, 옆에 담는 방법을 한 줄로 적었어. 열면 빈 종이 위에 가위선만 있어. 오류 화면이 아니라, 아직 비어 있는 작은 주머니로 보이게 했어.

D. 담기와 다시 쓰기

사이드바는 갤러리 화면에만 있고, 엽서 편집 화면에는 없어. 그래서 ‘담기’와 ‘꺼내 붙이기’는 편집 화면에서 하고, 사이드바의 파우치는 모아 둔 걸 구경하고 정리하는 곳으로 나눴어. 장면을 누르거나 그대로 두면 순서대로 넘어가.

움직임 메모

  • 닫힌 파우치에서만 움직여. 조각 세 개가 각각 3.1·3.7·4.3초 주기로 위아래 1.5~2.5dp, 좌우 1dp 안팎, 회전 ±2° 이내에서 천천히 오가. 파우치 입구 밖으로 나가거나 서로 크게 겹치지 않아.
  • 열린 보관함에서는 모두 멈춰. 고를 조각이 움직이면 누르기 어려워서야. 고른 조각만 3dp 들려 보여.
  • 보여 주는 조각은 최근에 담은 3개로 정했어. 많이 모여도 입구에는 3개만 보이고 나머지는 숫자(예: 12조각)로만 알려.
  • 이 목업은 화면 밖으로 스크롤된 휴대폰의 움직임을 멈추고, 기기의 ‘움직임 줄이기’ 설정이 켜져 있으면 처음부터 멈춘 상태로 보여 줘. 앱에서는 사이드바가 닫혀 있을 때 그리지 않는 게 기본이야(ModalNavigationDrawer는 닫히면 내용을 구성하지 않아).
  • 연못처럼 매 프레임 계산하는 방식은 필요 없어. 조각 3개를 무한 반복 트윈(infiniteTransition)으로 graphicsLayer에서만 움직이면 다시 구성(recomposition) 없이 그리기만 갱신돼. 앱에는 아직 ‘움직임 줄이기’ 설정을 읽는 코드가 없어서, 따르려면 새로 추가해야 해.
