권장 초안: 엽서당 1개, 형태·색·작은 장식만. 길이 조절·글귀·완성품 복제는 초기 범위에서 제외. 편집은 기존 것을 교체하고, 취소는 원래 책갈피를 유지해. 저장 성공 전에는 완성 안내를 띄우지 않아.

공유 이미지에는 초기 버전에서 제외하는 안을 권장해. 앱 안에서 끼운 종이를 보관하는 의미이고, 공유 시에는 엽서 내용만 출력한다는 안내가 필요해. 포함을 택하면 앞·뒷면 공통 renderer와 출력 여백을 함께 설계해야 해.

이 목업의 색·크기·모션은 비교 값이야. C2 천공은 HTML 근사이고 실제 앱의 공용 Path를 복제한 명세가 아니야. 연민트는 신규 콘텐츠 색 후보야. 사진은 외부 로딩 없는 가상 풍경이야.
