기억 밀도 목업 — 손그림 재료 비교

앱 밖의 독립 HTML 목업입니다(production 코드와 공유하는 것 없음). 얼굴·하트·overflow 표시를 지우고 하단엔 월 숫자만 남겼습니다. 종이·배치·막대 폭·데이터·높이 규칙은 모든 시안이 같고 재료 질감만 다릅니다. 질감은 고정 seed라 새로고침해도 똑같이 그려집니다.

공통 데이터: 0, 1, 3, 6, 9, 14, 20, 11, 2, 5, 17, 8장 (빈 달 ~ 매우 높은 달)
높이: 비교용 임시 비례식(20장 = 최대 높이). 단계 수는 아직 정하지 않음
종이: 모든 시안이 같은 seed의 종이 결을 공유 — 안료는 결의 볼록한 곳부터 묻음
