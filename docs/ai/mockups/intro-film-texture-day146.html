146일차 · 인트로 필름 재질 비교 (기준안 · A · B · C)

모든 시안은 같은 모션(AppIntroScreen.kt/IntroFilmPlan.kt 실측값: 이송 시작 280ms, 한 칸 720ms, cubic-bezier(.40,0,.12,1), 정착 후 140ms 뒤 손 도장 720ms, 260ms 유지, 갤러리 크로스페이드 180ms)과 같은 기하(칸 폭 = 화면 폭 40% → 153.6dp, 칸 높이 ×1.18, 위아래 띠 14dp, 지름 4.8dp 원형 천공 14dp 간격)를 쓴다. 재질만 다르다. 화면은 384×832dp(현 실사용 기기 1080×2340 / 450dpi 기준)이고, 날짜·방문 수·문구는 예시값이다.

기준안 — 현재 앱

  • 사진 필름이 아니라 아이보리 종이 필름이야. 칸마다 PaperSurface 단색, 안쪽 기록 칸은 PaperField + 1dp PaperDivider 테두리.
  • 천공은 PaperTray 색 원을 그린 것이라 실제로 뚫려 있지 않아. 어두운 확인판에서도 베이지 점으로 남아.
  • 필름 위아래 1dp 경계선은 Row의 drawBehind라 칸 배경에 가려서 실제로는 보이지 않아.
  • 바탕과 화면 배경의 명도 차가 작고 두께·결이 없어서 납작한 종이 띠처럼 보여.

A — 아날로그 종이 기록지형

  • 아이보리 종이 색과 구조는 그대로 두고, 미세한 종이 결·섬유와 위아래 가장자리의 얕은 따뜻한 농도를 더했어.
  • 천공은 종이를 실제로 뚫어서 배경이 보여. 위쪽에는 종이 두께 그늘, 아래쪽에는 잘린 단면의 밝은 선이 있어.
  • 회색 테두리 대신 갈색 잉크로 인쇄된 얇은 칸 선을 썼어.
Compose 예상: drawWithCache로 천공 차감 Path 1개, 칸 index 시드 섬유 Path(캐시), 64px 결 타일 1장. 새 이미지 없음. 비용 낮음(칸이 많으면 섬유 Path 수에 비례).

B — 아날로그 사진 필름형

  • 호박·갈색 반투명 네거티브 필름이고, 띠 쪽 농도가 조금 더 짙어. 칸 안도 종이로 덮지 않은 필름 면이야.
  • 날짜·소인은 기존 잉크(InkSecondary #5B5046)와 크기 그대로 필름 위에 찍혀. 가독성 저하를 숨기지 않았어.
  • 칸마다 다른 은은한 노출 흔적(고정 시드), 필름 그레인, 드문 먼지 점, 뚜렷한 천공 두께를 넣었어.
Compose 예상: 반투명 바탕 그라디언트 + 천공 차감 + 칸별 RadialGradient(캐시) + 그레인 타일. 새 이미지 없음. 비용은 A와 비슷하거나 약간 높아.

C — 종이·필름 혼합형

  • 위아래 천공 띠만 호박색 필름이고, 가운데 기록 영역은 아이보리 종이가 필름 위에 붙은 구조야.
  • 종이 띠 아래에 얕은 그늘을 깔아서 종이와 필름의 재질 경계를 만들었어.
  • 날짜·소인은 A와 같은 종이 위에 기록돼.
Compose 예상: A 구성 + 필름 띠 그라디언트·그레인. 새 이미지 없음. 비용은 A와 B 사이.

렌더링 방식: 필름(바탕·천공·칸·날짜·지난 소인·그레인)은 시안·상황별로 한 번만 오프스크린 캔버스에 그려 두고(정적 캐시), 매 프레임에는 앱의 graphicsLayer translationX와 같은 식 화면폭/2 − 칸폭 × (위치 + 0.5)으로 통째 옮기기만 한다. 그래서 그레인·노출 얼룩은 필름 좌표에 붙어 함께 움직이고, 프레임마다 다시 생성되지 않는다(깜빡임 없음). 천공은 destination-out으로 바탕을 실제로 지운다. 오늘 칸 소인은 앱과 같은 스프링(감쇠 0.5, 강성 2600, 0.94→1)으로 따로 그리며 필름과 같은 좌표에 붙는다. 손 이미지는 저장소의 seal_stamp_hand.png를 상대경로로 읽고, 없으면 손 없이 재생된다.
