① 글귀 패널 — 기준안 / A / B / C

기준안은 PostcardRenderSpec.drawMessage 값 그대로야(논리 2048px 기준): 흰 판 rgba(255,252,247,222/255)·반경 34, 번짐 없는 그림자 (+12,+14) rgba(20,14,26,55/255), 명조, 글자색 rgb(47,37,43), 글자 크기 길이별 62/56/50/44, 가운데 정렬, 최대 4줄, 오른쪽 아래 "▼" 표시. 우표 레이아웃 판 위치 (220,1505)–(1828,1748), 편지지 (96,1352)–(1952,1840). 모든 안에서 판 위치·글자 크기·정렬·줄 수는 그대로 두고 표면만 바꿨어. "▼"는 기준안 정체성이라 A안은 남기고, B·C안은 뺀 모습이야(아래 체크로 비교).

② 날짜 패널 — 기준안 / A / B / C

기준안: 흰 판 rgba(255,252,247,205/255)·반경 28, 명조 34, 글자색 rgb(70,58,68)=#463A44(자주빛 회색), yyyy-MM-dd 가운데. 우표 레이아웃 (544,1846)–(1504,1932). 글귀 패널은 기준안으로 고정하고 날짜만 바꿨어. A안 잉크는 아래에서 고를 수 있어.

④ 마스킹테이프 재질 — 기준안 / A / B / C

모든 안에서 길이·폭·색·무늬·회전·가장자리 모양·위치가 같아. 기준안: 외곽선으로 자른 단색 판(알파 0.78, 크라프트 0.82, 아이보리 0.70, 사진 0.85) + 무늬(알파 0.55). 그림자·결 없음. 엽서 안 배치: 사진 모서리(민트 체크·모서리 자름), 빈 곳(크라프트·일자), 겹침(라벤더 도트·양쪽 찢김 위에 연분홍 하트·한쪽 찢김), 어두운 커스텀(남색+별), 사진 테이프. 아래 띠는 가장자리 4종을 2배로 확대한 거야. 질감은 테이프마다 고정 시드로 한 번 만들고 테이프 자기 좌표에 붙어서 같이 움직이는 방식으로 그렸어(달력 테이프와 같은 원리, 크기만 엽서 테이프에 맞춤).

⑤ 낙서 · 형광펜 · 점선 — 같은 점 좌표로 비교 후순위

같은 가상 필기(점 간격은 빠르게 그은 구간일수록 넓어지게 흉내)를 기준안/개선안으로 그렸어. 기준안: 점을 직선으로 잇기, 둥근 끝·둥근 이음, 굵기 일정(얇게 16·중간 30·굵게 50), 형광펜은 굵기×1.9·알파 96, 점선은 [0.1, 굵기×2.2] 대시. A안은 저장된 점을 그대로 지나가는 중점 곡선이라 새 획을 만들지 않지만, 꺾인 모서리가 둥글게 바뀌어 기존 낙서도 모양이 조금 달라져. B안의 획 끝 가늘어짐은 필압을 지어내는 것에 가까워서 신중해야 해. 아래 회색 점은 저장된 실제 점 위치야.

⑥ 배경 안쪽 흰 테두리 — 현재 / 옅게 / 없음

현재 drawBackground가 모든 엽서(모든 레이아웃·모든 배경)에 안쪽 32px 위치, 굵기 8px, 흰색 알파 115/255 사각선을 그려. 7/3 커밋 688dd5b부터 있었고(7/2 첫 백업 c1c4fce 이후), 의도를 적은 기록은 찾지 못했어. 밝은 배경에선 거의 안 보이고 어두운·진한 배경에서 액자처럼 드러나. 현재 단계에선 제거하지 않아.
