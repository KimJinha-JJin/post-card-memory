실제 구현처럼 상단 열린 파우치는 118.8×79.2px, 조각과 글자 없이 정적이야. 종이 위 조각은 3열·셀 76px·그림 50px. 조각을 누르면 양쪽의 선택 고리만 함께 바뀌어.

  • 기준 feature/photo-sticker / HEAD 4b865df. 110일차 보호 목업은 수정하지 않고 새 파일로 만들었어.
  • A의 132×88 외곽,앞판 top30/44,뒷판 top12/4,조각 슬롯(20,3)/(52,7)/(84,2),회전−3/+2/−1.5도와 글자 좌표는 현 코드 기준이야. 외곽 jitter·인쇄 줄의 난수는 Kotlin과 다른 브라우저 난수 재현이므로 픽셀 일치본은 아니야.
  • A는 원형 망점 2.2×1.9 간격·0.84 지름·alpha0.1과 코드 인쇄 줄을 사용해. B는 기존 종이 raster와 HTML/SVG 인쇄 가정이야. 새 PNG를 만든 결과가 아니야.
  • 샘플 조각은 HTML 안에서 그린 바다·잎·꽃 그림이야. 사용자 스티커나 앱에서 decode한 실제 모양이 아니며,원본 Crop/누끼 Fit 차이는 예시로만 나타내.
  • 선택 고리·−3px 올림은 시각 비교용. 삭제·재사용·저장·복원·navigation 로직은 구현하지 않았어. '통에서 빼기' 문구도 비활성 표본이야.
  • 움직임은 기존 3.1/3.7/4.3초 주기의 입구 조각만 비교하는 근사 CSS야. 기본은 정지이고 보관함 조각은 항상 정적이야. 앱의 닫힘·전환 lifecycle이나 프레임 성능을 검증하지 않아.
  • 연결된 브라우저가 없어 실제 렌더링·클릭·글꼴·작은 화면 시각 검수는 미완료야. 코드 기준 비교 의도는 재질만 바꾸고 가림·배치를 보존하는 것이야.
  • 304px 바깥 폭과 24px padding은 현 코드 기준,280px는 제약 관찰용 가정이야. HTML을 저장소 밖으로 옮기면 상대 경로의 기존 종이 PNG도 필요해. 외부 폰트나 네트워크 서비스는 사용하지 않아.
